# Pulse - MERN Project Management App

Pulse is a project and task management web application built using the MERN Stack.  
It helps teams manage projects, assign tasks, track progress, and collaborate easily.

---

# Project Functionality

## Authentication
- User Login and Registration
- JWT Authentication
- Role-Based Access Control

## User Roles
- Admin
- Manager
- Member

## Project Management
- Create, update, and delete projects
- Add project members
- Track project progress
- Project status management

## Task Management
- Create and assign tasks
- Update task status
- Set task priority and due dates
- Track overdue tasks

## Kanban Board
- Drag and drop tasks
- Organize tasks by status
- Real-time task workflow management

## Dashboard
- Project statistics
- Task analytics
- Recent activity tracking
- Charts and progress overview

## UI Features
- Responsive design
- Toast notifications
- Form validation
- Modern user interface
